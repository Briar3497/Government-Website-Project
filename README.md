Example of a Government travel site of the state of Alabama

Work is based on a college project requiring us to create a two-page layout for a state government website, then build a website including an introductory page, the
  capital, two non-capital cities, and a contact web form that verifies the required fields are entered and both the initial and confirmation emails match.
  
The Web form is for collecting information only, not for use on the web API

The site is built on Visual Studio Code and runs best when opened with a live server.
